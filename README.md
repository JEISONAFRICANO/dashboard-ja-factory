# J&A Factory Dashboard

Sistema administrativo responsive desarrollado con HTML, CSS y JavaScript para la gestión de ventas, clientes, inventario y reportes de la empresa textil J&A Factory.

---

# Descripción

Este proyecto consiste en un dashboard administrativo moderno orientado a la gestión empresarial y control de ventas.

El sistema permite:

- Registrar ventas
- Visualizar clientes
- Gestionar inventario
- Generar reportes
- Imprimir ventas registradas
- Adaptarse a escritorio, tablet y móvil

---

# Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript
- CSS Grid
- Media Queries
- Responsive Design

---

# Características principales

## Dashboard Responsive

El sistema se adapta automáticamente a:

- Escritorio
- Tablet
- Dispositivos móviles

---

## Gestión de Ventas

Permite registrar:

- Cliente
- Vendedor
- Producto
- Valor de venta

Las ventas se almacenan dinámicamente en tablas visuales.

---

## Reporte de Ventas

El sistema genera automáticamente:

- Historial de ventas
- Reporte administrativo
- Vista organizada de registros
